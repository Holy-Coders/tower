## Stage log

- [x] **Fix A — landing keeps claims (N1)** — `finalize_landing` no
  longer calls `release_claims`; the landing receipt and the
  `changeset_landed` event now carry `claims_held` (plus `assignment_id`
  on the event). `assignment close` verified to already release all of
  the assignment's claims and pinned by a new test. The dead
  `Store::release_claims` wrapper was removed
  (`release_claims_nodes(.., None)` is the one path).
- [x] **Fix B — Rust test functions are individual items (N2, indexer)**
  — `walk_rust` descends into inline modules' `declaration_list`s; each
  test function in a `#[cfg(test)]` module is its own item named by the
  function; the synthetic `tests` item and any name-based special case
  are gone. Bodiless `mod foo;` keeps a `module` item. TypeScript
  checked: no analogous synthetic item exists; left unchanged
  (DECISIONS 22).
- [x] **Fix C — outside-claim detail where the hint is (N2, output)** —
  changed items are `(file, item)` pairs end to end; coverage is
  file-scoped; `outside_items` are `{"file", "item"}` objects; a wholly
  outside file is reported once, not once per item. Reasons are
  generated by `engine::outside_reason`
  ("touched files outside claim: src/orders.rs#discount_is_tenth,
  src/notify.rs (whole file)") in the text board, `changeset status`,
  and MCP. CLI + MCP share `board::changeset_status_value`, which adds
  `claimed_vs_actual` (board shape) to every previous field.
